New to this? Show me exactly where everything goes

1. Find Instagram's saved folder

After downloading and unzipping your Instagram data, open the folders until you find saved. You should see files similar to:

saved/
├── saved_posts.html
├── saved_collections.html
└── saved_music.html

2. Put the app inside it

On GitHub, click Code → Download ZIP, unzip it, and move the app folder into the same saved folder:

saved/
├── saved_posts.html
├── saved_collections.html
├── saved_music.html
└── instagram-saved-library/
    ├── run.bat
    ├── app.py
    └── public/

3. Windows: start the app

With Python installed, double-click run.bat. A browser window opens with your library. You do not need to type commands or know how to program.

4. Where do I get Python?

Use the official Python website. During installation, if the installer shows “Add Python to PATH”, make sure it is checked before installing.

Official Python download ↗

5. Don't want Python?

Use the browser-only method above. It works without Python, but you will select your exported HTML files each time.

Common questions

Looking for this?

How do I save my Instagram posts before deleting my account?

Request your Instagram data export, include Saved items, then open the export with Instagram Saved Library.

How do I view Instagram saved posts from an HTML export?

This app turns the exported HTML saved-post data into a visual, searchable library instead of plain files.

Can I keep my saved Instagram Reels after deleting Instagram?

You can keep the exported saved links and library on your computer so you can revisit them outside Instagram.

Do I need to upload my Instagram data?

No. The app is designed to run locally with your exported files. No Instagram login is required.

Take your saves with you.

Download your Instagram data. Put the app beside it. Open your library. That's it.
